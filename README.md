# Prolog Family Relationship Program

## Aim
To implement family relationships using Prolog facts and rules.

## Description
This program represents family relationships using parent, male and female facts.
Rules are used to identify sister, brother, grandma and grandpa relationships.

## Software Used
- SWI-Prolog
- Visual Studio Code
- GitHub

## Program
The Prolog program is available in `family.pl`.

## How to Run

1. Open the terminal.
2. Start SWI-Prolog:

```text
swipl
